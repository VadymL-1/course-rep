# Question 1 
**Поясніть етапи завантаження системи Linux.** 

>Після увімкнення комп'ютера запускається _BIOS_, який перевіряє та ініціалізує основні апаратні компоненти, після чого визначає пристрій для завантаження операційної системи. BIOS передає керування завантажувальному коду диска.

>Далі запускається завантажувач _LILO_ (Для старіших систем з завантажувальною системою _MBR_) або _GRUB_ (Для новіших систем з завантажувальною системою _UEFI_). Його основне завдання — знайти ядро Linux, завантажити його в оперативну пам'ять і передати йому керування. GRUB також може дозволити користувачу вибрати потрібну версію ядра або іншу операційну систему.

>Після цього починає працювати _Kernel_ (ядро Linux). Воно ініціалізує пам'ять, процесор, пристрої та необхідні драйвери, а потім запускає перший процес користувацького простору — _init_ з PID 1. У сучасних системах його роль зазвичай виконує systemd.

>На завершальному етапі _init_ запускає необхідні системні служби та переводить систему у відповідний _run level_. У класичних системах run levels визначають режим роботи системи, наприклад багатокористувацький режим без графічного інтерфейсу або з ним. Після цього система готова до роботи користувача.

# Question 2
**Як переглянути системні журнали?**
Є декілька варіантів прегляду системних журналів
* > journalctl

>> Використовується для перегляду автоматично створених логів які згенеровані утілітою _systemd-journald_. Для виклику справки допомоги по утіліті можна виокристати прапорецб _-h_

* > /var/log/*

>> Де * це назва одного з логових файлів. Традиційно система записує логи у відповідні файли в дерикторії _/var/log/_ що дозволяє перевірити записи за допомогою команд таких як _cat_, _tail_, _head_ або використовуючи редактори коду такі як _nano_.

* >dmesg

>> Окремо є можливість перегляду логів ядра за допомогою команди _sudo dmesg_ (ВАЖЛИВО: команда потребую прав root)

# Question 3 
**-rw------- : Опишіть цей дозвіл. Як додати прапорець виконуваного файлу?** 

> Це прапорець дозволу для файлу оскільки перший біт в записі залишений пустим (що вказує на те що це не дерикторія.).

> _rw-_ - це права які розповсюджуються на власника файлу, оскільки записані в першому триптихі. Для всіх інших (групи користувачів яка вказана як група власника, та всіх інших користувачів) доступ до файлу закритий. Відсутні права на читання, запис або виконання файлу. 

>> Для того аби додати прапорець виконуваного файлу потрібно використати команду _chmod_ та задати значення або в числовому форматі дозволи _700_ або прописати вручну дозволи _-rwx------_ за умови якщо дозволи потрібно надати лише власнику файлу. Де _r_ - це права на читання файлу, _w_ - права на внесення змін, _x_ - права виконувати файл.

# Question 4    

**Яка різниця між apt і dpkg?**

> apt

>> Система керування пакунків який дозволяє всатновити, оновити або видалити програми. Особливістю способу встановлення або оновлення полягає в тому що пакунки мають бути розташовані у мережевих репризеторіях. 

>> Синтаксис команди: *sudo apt опції команда ім'я_пакунка*

> dpkg

>> Дозволяє проводити встановлення, оновлення або видалення пакунків. Встановлення та оновленяя відбувається для завчасно завантажених пакунків з самої системи. Навідміну від _арt_ ця программа не буде створювати залежності а лише проведе процес встановлення. 

>> Синтаксис команди: *sudo dpkg -i назва_пакунку.deb*
